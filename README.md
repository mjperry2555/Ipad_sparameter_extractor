Coupling Matrix Extractor & Live Tuner Python tool for robust N-pole inline bandpass filter extraction from measured S2P/Touchstone data. Performs global magnitude multi-start search followed by complex S-parameter refinement (with reference-plane delays), Jacobian identifiability analysis (uncertainties, correlations, ambiguity detection), and model-based Level-1 electrical tuning advice ranked by normalized error. Includes a real-time live matrix editor (HTML/JS) that updates S11/S21 against measured data as parameters are adjusted, plus target comparison and export. Designed for Pyto on iPad (numpy/scipy/matplotlib). Supports design specification entry, demo generation, and full workflow from measurement to ranked tuning recommendations.
